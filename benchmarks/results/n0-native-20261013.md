## Native construction

licence dialog reported 30 days remaining. No account, activation, purchase,
installation or trial reset occurred. The owned process was closed afterwards.

[recipe.json](../datasets/shop/native/recipe.json) identifies all 15 exact source
files and hashes. Each source was imported through the real application's file
dialog. Multiple shapes were grouped, duplicated with the native Duplicate
command and repositioned before Save Project and Export. Single closed paths
remain ungrouped, providing both grouped and ungrouped examples. The source and
duplicate have equal resolved geometry but different top-level XForms.

A common original feature coupon is prepared from the earlier native probes:
Cut with kerf 0.2 mm and arc leads 3 mm at 45 degrees, Score, Fill engraving,
editable text with BackupPath, three bitmaps sharing one embedded image, a set
StartV, mirrored/rotated nested geometry, and a T1 rectangle. The prepared coupon
input is marked as agent-authored preparation and excluded from the 15 native
projects. Final project and export bytes are written by LightBurn. The source
design's licence governs each derivative, with an explicit modification notice.

The ordinary export settings remained at their observed defaults: Export Arcs,
0.050 mm curve tolerance, SVG 96 DPI with auto-detection, DXF unit auto-detection
with mm fallback and 0.010 mm auto-close. The chosen DXF file format is the
dialog's AutoCAD Legacy option (AC1009, `$INSUNITS=4`). Convert Arcs to Lines was
enabled only for the five extra exports and restored afterwards.

## Independent collection audit

Run `.cache/shop-venv/Scripts/python.exe scripts/shop_native_audit.py`.
The [machine-readable record](n0-native-20261013.json) contains per-file checks:

- All 15 projects retain the required layer families, kerf, lead settings,
  editable text backup, StartV and three shared images.
- All shared geometry resolves; the two imported source copies match after
  resolving vertex/primitive sharing, apart from their top-level transforms.
- All 15 ordinary DXFs parse with ezdxf 1.4.4. Their complete vector bounds match
  the corresponding SVG viewBoxes within **0.000054 mm**. This does not prove
  contour fidelity, part labels or Nestbolt's import behavior.
- All five native legacy line exports fail ezdxf, including a separate recovery
  attempt, with `DXFStructureError: Expected DXF entity POLYLINE or SEQEND`.
  Their raw POLYLINE and SEQEND counts differ, and CIRCLE records remain. Original
  bytes are kept as real writer outputs, not repaired or replaced with cleaner
  fixtures. The importer will need to handle them or provide an actionable
  failure under H2's thresholds. Some ordinary files also trigger non-unique
  handle warnings; those warnings are recorded by file.
- Offline source-lock verification passes for all 339 asset/notice entries.
- All 409 staged source, licence, original-probe and native-output byte hashes
  match their manifests; Git preserves the native/source line endings. The six
  source-collector safeguards and the original format-probe audit pass again.

The audit checks that the observed line-export defect is explicitly recorded;
it does **not** call that defect a successful import. The collection check's
pass status is deliberately separate from the H1/H2/H3 flags, which remain false.
