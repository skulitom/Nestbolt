## Method

The original short phase runs first. Within the remaining original allowance,
the candidate derives a target from the remaining source after selection.
It charges the scan and keeps the original crop when no member remains.
The joint helper repairs only the selected pair, checks both exact containers
and lowers source parts using the existing bounded sampling.
Material-flat steps require canonical source-area descent. A joint sequence
commits only after strict whole-job material improvement; otherwise layout,
tracker and accepted counts roll back. The original deadline, four-step cap,
validation reserve and geometry guards remain.
[Qualification](h5-frontier-preparation-20261018.md) retains all 171 passing
native tests, including 166 unchanged prior bodies and five new policy tests.
All 139 prior recorded outputs remain exact. Seven new-policy saved-layout
checks and 34 filled-outer pairs pass, plus six public outcomes, six public
CLI checks and 856 public filled-outer pairs. Strict lint and build pass.

Four jobs, two kerfs, seeds 0–2 and three arms produce 72 outcomes. Ordinary
baseline, common baseline and common candidate run sequentially on the same
physical CCD0 core in rotating order; at most eight blocks run together.
Each search gets 60 seconds. Frozen geometry, quantities, stock and rotations
are unchanged. Block, score, case and measurement methods are AST-identical
to the preceding pilot. Every outcome requires independent validation and
public export; common mode must reserve hole interiors.
The session took 8.943 minutes.
