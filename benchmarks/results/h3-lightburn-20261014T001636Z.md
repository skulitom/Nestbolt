## Native observations and independent verification

The four default-origin projects contain rigid groups, editable cached Text,
three shared Bitmaps, shared vectors, Cut/Score/Fill/Image settings and a fixed
T1 reference rectangle. Their CUT layer retains 1200 mm/min, 35% power,
0.2 mm outward kerf, and a 3 mm arc lead-in at 45 degrees. SCORE remains
6000 mm/min at 20%; ENGRAVE remains Fill at that speed/power. Images retain
their independent settings. The existing T1 layer and reference shape remain
unchanged; a separate sheet outline is added on T1.

The mirrored probe was opened and saved with the **top-right device origin**;
the other projects used bottom-left. Native numeric coordinates agree with the
layout in both cases. The original No Machine device size (300 × 200 mm) and
bottom-left origin were restored. LightBurn was closed, the desktop restored to
1280 × 720 at 100%, and the Anode lease released. No machine was connected.

The [passing report](h3-lightburn-20261014T001636Z/native-check.json) records:

- 34 before/after dialog-page comparisons, covering **648 control values and
  states**, backed by 68 screenshots and accessibility observations;
- all **23 original setting instances** canonically equal in source, product,
  native baseline and native output saves, including the four original T1s;
- 16 individual unit selections and ten overall drawing bounds, read from
  LightBurn's own fields; the largest discrepancy is the curved mirrored probe's
  displayed width, 0.0036514 mm, below the 0.01 mm limit;
- **409 leaf comparisons / 537 contours** against native Save As geometry via
  the published MIT `lbrn2-to-svg@0.5.3` oracle, with the documented test-only
  normalization, 64 samples per contour and 0.0005 mm flattening tolerance;
- maximum bidirectional point difference **0.0005267 mm**, bounds difference
  **0.0005297 mm**, and image-corner difference **0.00001073 mm**;
- five allowed canonical XML diffs and five independently valid layouts.

The only newly generated CutSetting belongs to the mirrored probe. Native Save
As normalizes its name from SHEET to T1 and adds priority 3. The verifier checks
those exact new defaults separately; every original setting remains exact.
The older bitmap-only probe's priority discrepancy remains in its own report.
