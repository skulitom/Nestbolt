# v1.1 initial corpus collection and LightBurn format probes

**Partial evidence only: H1 and H3 are not passed; completed milestone weight is 0%.**
The goal was started on 2026-10-13. No importer or solver changes are included.

The [source lock](../datasets/shop/sources.lock.json) contains 74 real drawings
(63 DXF and 11 SVG) from nine permissively licensed repositories. All 86 source
and licence-document checksums pass `python scripts/shop_sources.py --check`.
An independent ezdxf 1.4.4 inspection opens all 63 DXFs. Twenty-five meet the full
research Fusion fingerprint; seven identify FreeCAD. Writer classification of
the remaining files is pending. The [draft manifest](../datasets/shop/manifest.draft.json)
deliberately has no labels or split yet; no hold-out has been consumed or frozen.

The collection tool restores only pinned, reviewed source bytes and refuses
licence exclusions, unpinned source URLs, path escapes and checksum drift. Its
six targeted tests pass (`python -m unittest discover -s scripts -p test_shop_sources.py`).
Git initially attempted to normalize native CRLF files and flagged original CAD
whitespace. Scoped `.gitattributes` now preserve source, licence and probe bytes;
all 104 staged source/evidence/probe hashes match their recorded originals.
Reproduce that check with `python scripts/shop_probe_audit.py --git-index` after staging.

LightBurn 2.1.01 ran in Anode, with a 300 × 200 mm `No Machine` device. Its title
bar says Pro; no edition change, upgrade or trial action was performed. The
original MIT probes under `benchmarks/datasets/shop/probes/` were saved through
LightBurn. [LBRN2.md](../../docs/LBRN2.md) records the findings and individual files:

- All four origin flags verified; Shape subtrees stay canonically identical.
- Independent primitive/vertex sharing, rotated/mirrored groups, editable text
  with BackupPath and three bitmap copies sharing SourceHash 0 are present.
- Kerf and line/arc lead fields verified against saved XML. UI 1,200 mm/min is
  saved as speed 20 mm/s.
- Fill plus Line is a Scan setting with a Cut SubLayer. Image and vector settings
  can both have index 0. An index-only layer map is insufficient.
- Set Start Point adds StartV=2 without changing the shared path geometry; only
  this attribute and Thumbnail differ in the isolated before/after files.
- Palette RGB/ACI values measured. Native DXF export/import maps the T1 outline
  to C05; exact true colour does not preserve its tool-layer identity either.
  Both native Modern and Legacy DXF exports explicitly carry millimetre units.

the [machine-readable report](n0-n2-initial-20261013.json), including hashes and
method issues. These structural checks are not an independent geometry oracle,
an importer fidelity pass or a nesting round-trip gate.
