## Method and results

The `lightburn_place` example calls the actual core preserving writer with an
explicit rigid placement, 300 × 200 mm workspace and no added outline. It does
not search. Eight outputs retain exactly one top-level unit; canonical checks
allow only its placement matrix, required shared definitions and omission of the
other units. Every original CutSetting, image setting and other document element
remains unchanged in the **Nestbolt output**. Group children and Text BackupPath
XML remain unchanged, including the intentionally stale cached transform.

Installed LightBurn **Pro 2.1.01** opened every output without a warning dialog.
Measurements used Select All, the centre reference point and native millimetre
position/size fields. Each screenshot is retained, together with the native
Save As file. There were no font-missing warnings for this Arial text fixture.

## Native behaviour confirmed

**Text:** translation and a 90° rotation follow the live Text XForm. Native Save
As refreshes the BackupPath XForm to the new world transform. Nestbolt need not
rewrite the cached child XML for these probes. The native UI's displayed curve
bounds are slightly different from analytic bounds, as already seen in H2.

**Sharing:** keeping only the second Bitmap copy after omitting its Data owner
still displays the original checkerboard. Nestbolt re-homes the exact Data
attribute. The native saved image data and independent corner check agree.

**Origins:** the four source `MirrorX`/`MirrorY` combinations retain identical
numeric placement in the bottom-left No Machine device. With the device changed
to top-right, both bottom-left and top-right source files still show centre
(30, 32.5), size (40, 25). The rulers and drawing reflect with the device axes:
[top-right source](h3-native-probe-20261013T224854Z/device-top-right-source-top-right.jpg),
[bottom-left source](h3-native-probe-20261013T224854Z/device-top-right-source-bottom-left.jpg).
On Save As, LightBurn writes origin flags matching the active device. A mismatch
marks the opened project dirty (`*`) without a warning dialog. Do not apply a
second reflection to top-level placement coordinates based only on the root
flags. This establishes device-coordinate placement, not identical physical
screen orientation across different device origins.

## Settings limitation retained

The product's canonical checks preserve **all** settings in all eight outputs.
LightBurn's own serializer omits unused vector/image layers. Its retained
settings are canonically identical in nine of ten native saves. In the isolated
bitmap output, native Save As additionally changes image-layer `priority` from
**3 to 0**; the image's other setting fields are identical. The final JSON
therefore retains `passed: false`, including the exact field diff. This is not
waived or used to claim H3 completion. Full before/after cut-settings dialogue
checks on five actual nested projects are still required.
