## Reproduce on Windows

From the tested revision, run the following in PowerShell 7 on the reference machine with Python and psutil installed. The build uses logical CPUs 16–31. The runner selects the two release test executables from Cargo's build log.

```powershell
New-Item -ItemType Directory -Force output | Out-Null
python -c "import psutil, subprocess, sys; psutil.Process().cpu_affinity(list(range(16, 32))); sys.exit(subprocess.call(sys.argv[1:]))" `
    cargo test --locked --release -p nestbolt-core --test import_habits --test search_fuzz --no-run --message-format json > output/h2-habits-build.jsonl
python scripts/h2_habit_fuzz.py --build-log output/h2-habits-build.jsonl
```

The run used generated inputs exclusively. H2 remains open under the [held-out decision](h2-gate-decision-20261020.md).
