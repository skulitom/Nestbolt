# N0 reference labels and native correction — 2026-10-13

Authoring checkpoint; completed v1.1 milestone weight is **0%**. H1 is not frozen,
and no N1 importer or solver change has begun. The [integrity audit](n0-labels-20261013.json)
checks **294 labels**: 74 real, 50 locally written LightBurn outputs and 170
generated fixtures. The 44 public LightBurn project labels remain before the
stratified split and H1 freeze.

## Reference method

The agent reviewed the real and native exports rendered through ezdxf 1.4.4's
drawing add-on or Inkscape 1.4.4, together with raw entities, layers, colours and
units. There are 104 distinct saved renders, with source licences and hashes in
the draft manifest. White-on-white DXF strokes were rendered black in three
cases; metadata retains their original colours.

Bounds come from independent ezdxf/svgpathtools curves, with 0.0002 mm flattening
and GEOS polygonization after endpoint clustering. Explicit review decisions
check part/hole counts before writing labels. This code does not call Nestbolt.
Default joins use 0.005 mm. The two ARC controller panels need explicit 0.025 mm
and 0.05 mm closure options; the labels retain the default failure, gap sizes
and chosen tolerance. DXF inch headers are honoured even where numeric dimensions
look like mm; the label notes the discrepancy without silently correcting it.

Eleven inputs are negative fixtures: two empty real SVGs, four incomplete or
ambiguous real drawings, and the five malformed native legacy line exports.
Their actionable rejection contracts are explicit. **They do not earn an H2
successful-import result.** Closed regions in incomplete drawings are retained
as observations rather than being called a complete cut job. For malformed
native DXFs, intended parts come from the paired valid native export, whose
render and hash are identified; no successful render/parse of malformed bytes
is claimed. The zero-length SVG paths were also checked in raw source.

Native `.lbrn2` labels preserve the three nesting units (feature coupon and two
source copies) and one fixed T1 rectangle. Group bounds include score/engrave
content, text and all three bitmaps, read from the paired native SVG export;
disconnected children still form one rigid group. The ordinary DXF/SVG labels
explicitly select black CUT content, excluding score, engraving and T1.

## Pre-freeze native correction

The render/topology review found a small overlap between the coupon and the
second wide source copy in lb-06/07/08/10. The coupon group was moved +400 mm
in staging, then each project was opened and saved by LightBurn 2.1.01 and both
native exports repeated. The 12 previous originals remain in commit `8bbc1fb`;
old/new hashes and the exact workflow are in the native recipe. The
[corrected native view](n0-native-20261013/coupon-separated.png) shows separation.

Native saving renumbered shared-list IDs, serialized default Group CutIndex=0,
updated the text BackupPath cache and regenerated Thumbnail. After resolving
those specific changes, all geometry and settings match. The coupon's top-level
X translation and its text BackupPath's cached world X translation both increased
by exactly 400 mm. No shape geometry, source-copy placement or cut setting changed.

The [corrected native audit](n0-native-corrected-20261013.json) passes all 15
projects and ordinary DXFs. Corresponding **vector** bounds agree within
**0.000008 mm**. The SVG viewBox also includes bitmaps, absent from DXF, so its
full extent is no longer an appropriate vector-bound comparison after the
coupon move. The audit now checks actual SVG vector bounds, including the hidden
T1 rectangle, and retains the old viewBox comparison separately.

## Independent oracle limits

The unmodified published MIT `lbrn2-to-svg@0.5.3` package was run on all 59 public
and native projects. Its dependencies and integrity hashes are pinned under
`oracle-tool/`. Conversion returning an SVG is not a completeness check: warnings
show skipped Polygon, compact LineOpen primitives, Text without BackupPath and
shared Bitmap data. Its nested text BackupPath handling double-applies ancestor
translation in the local coupon. Native SVG exports provide independent evidence
of the actual text position. These limits must be accounted for in H3; none is a
Nestbolt import/round-trip pass.

## Authoring issues retained

The initial worksheet needed fixes for Illustrator SVG switch fallbacks, CSS
fill colours, undefined DXF layer references and empty SVG drawing extents.
One keyboard drawing contains 29 thin closed rings plus a distant 0.1 mm closed
mark; its initial visual count was caught by the explicit hole-count check and
corrected after inspecting the mark. The ARC top-panel hole count was likewise
corrected from 13 to 11 by file reading and the count guard. A broad diagnostic
trying large join tolerances on outlined lettering was stopped; those variants
were not used as labels. The earlier worksheet candidates remain scratch data.

hashes, six collector safeguards and 339 pinned upstream-byte entries pass.
