The candidate continues after strict material improvements, accepting at
most four exchanges in one window. Every attempt shares the original
absolute deadline and retains all original geometry/material guards.
Rejection or an accepted flat result stops the sequence. The qualified
free-space return seed, proposal choices and per-attempt repairs remain.
[Qualification](h5-exchange-chain-preparation-20261018.md) retains 141 passing
tests: all 137 prior tests unchanged and four new regressions. Exact source
reconstruction, public replay, authored geometry checks, lint and build pass.
The old-behavior regression failures and preparation syntax failure remain.

Four jobs, two kerfs, seeds 0–2 and three arms produce 72 outcomes. Ordinary
baseline, common baseline and common candidate run sequentially on the same
physical CCD0 core in rotating order; at most eight blocks run together.
Each search gets 60 seconds. Frozen geometry, quantities, stock and rotations
are unchanged. Block, score, case and measurement methods are AST-identical
to the preceding pilot. Every outcome requires independent validation and
public export; common mode must reserve hole interiors.
